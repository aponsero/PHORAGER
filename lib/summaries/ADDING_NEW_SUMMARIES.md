# Adding a New Summary Type to Phorager

Summary tables are generated by the `phorager summarize` command, which
runs the `SUMMARIZE` Nextflow process inside the `parsing_env` environment.
Each summary type is a self-contained Python class in `lib/summaries/`.

Adding a new summary type requires changes to **two files only**:

1. A new file in `lib/summaries/`
2. One line in `lib/commands/summarize.py`

---

## Step 1 — Create the summary class

Create `lib/summaries/my_new_summary.py`. Use the template below:

```python
from pathlib import Path
import pandas as pd
from summaries.base import BaseSummary
from summaries.registry import registry


@registry.register
class MyNewSummary(BaseSummary):

    name        = "my_new_summary"          # used with --type
    description = "One-line description"    # shown in --list

    def required_files(self, annotation_outdir=None, **_):
        """
        Return {label: Path} for every file that MUST exist.
        Validation fails with an error if any are missing.
        Use annotation_outdir, bacterial_outdir, or both as needed.
        """
        a = Path(annotation_outdir)
        return {
            "Some required file": a / "3.Annotation/some_required_file.tsv",
        }

    def optional_files(self, annotation_outdir=None, **_):
        """
        Return {label: Path} for files that are used when present but
        whose absence only triggers a warning, not a failure.
        Omit this method entirely if all inputs are required.
        """
        return {
            "Some optional file": Path(annotation_outdir) / "3.Annotation/optional.tsv",
        }

    def generate(self, annotation_outdir=None, bacterial_outdir=None, **_):
        """
        Read input files and return a tidy pd.DataFrame.
        Never write files here — the runner handles output format and path.
        """
        a = Path(annotation_outdir)
        df = pd.read_csv(a / "3.Annotation/some_required_file.tsv", sep="\t")
        # ... your logic here ...
        return df
```

**Rules:**
- `name` must be unique across all summary classes.
- `generate()` must return a `pd.DataFrame`. Never write files inside it.
- Accept `**_` in every method signature so unused dir arguments are silently ignored.
- Use `keep_default_na=False` in any `pd.read_csv()` call that reads biological
  data — this prevents biological strings like `"NA"` from becoming float NaN.

The `__init__.py` auto-discovery will pick up the new file automatically.
No changes to `__init__.py`, `registry.py`, `base.py`, or `summarize.nf` are needed.

---

## Step 2 — Register the type in the CLI

Open `lib/commands/summarize.py` and add one entry to `_KNOWN_SUMMARIES`:

```python
_KNOWN_SUMMARIES = {
    "bacterial_genome": "Per-genome QC metrics (CheckM2) with prophage counts",
    "prophage_table":   "Per-prophage table: host, cluster, CheckV quality, length, CDS count",
    "my_new_summary":   "One-line description",   # <-- add this line
}
```

This is the only place outside `lib/summaries/` that needs to change.
It controls what appears in `phorager summarize --list` and what the CLI
accepts as valid `--type` values before invoking Nextflow.

---

## Step 3 — Test

Add a test file `tests/test_my_new_summary.py` following the patterns in
`tests/test_bacterial_genome.py` or `tests/test_prophage_table.py`.

At minimum, test:
- `generate()` returns a DataFrame with the expected columns
- `validate()` returns `ok=True` when all required files are present
- `validate()` returns `ok=False` when a required file is missing
- Any edge cases specific to your parsing logic (empty files, missing columns, etc.)

Run with: `pytest tests/test_my_new_summary.py -v`

## Available pipeline output paths

| Workflow | File | Path |
|---|---|---|
| Bacterial | CheckM2 quality report | `{bacterial_outdir}/1.Genome_preprocessing/Bact1_CheckM2/quality_report.tsv` |
| Annotation | CheckV quality summary | `{annotation_outdir}/3.Annotation/Anno1_CheckV/checkv_output/quality_summary.tsv` |
| Annotation | Filtered annotation output | `{annotation_outdir}/3.Annotation/Anno5_FilteredResults/filtered_annotation_output.tsv` |
| Annotation | Filtered phage set | `{annotation_outdir}/3.Annotation/Anno6_Clustering/filtered_phage_set.fasta` |
| Annotation | Cluster information | `{annotation_outdir}/3.Annotation/Cluster_information.tsv` |
| Annotation | Final representatives | `{annotation_outdir}/3.Annotation/Final_representatives.fasta` |
| Prophage | All coordinates | `{prophage_outdir}/2.Prophage_detection/All_prophage_coordinates.tsv` |
| Prophage | All sequences | `{prophage_outdir}/2.Prophage_detection/All_prophage_sequences.fasta` |
